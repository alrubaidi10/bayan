# بيان ERP — دليل حماية الكود وتثبيت النظام (سطح المكتب والجوال)

يقدم هذا الدليل كل ما تحتاجه لتثبيت النظام للعميل كبرنامج محمي دون إظهار السورس كود، بالإضافة لتشغيله كتطبيق جوال.

---

## 1. تطبيق سطح المكتب للكمبيوتر (ملف تثبيت Windows .exe محمي 100%)

### كيف تتم حماية الكود؟
- يتم تحويل كود الخادم (Backend) وكافة المنطق المحاسبي والمخزني من صيغة JavaScript النصية العادية إلى **بايت كود ثنائي مجمّع (V8 Compiled Bytecode بصيغة `.jsc`)** باستخدام أداة `bytenode`.
- الكود الثنائي غير قابل للقراءة أو التعديل من قبل العميل، حيث يستبدل الكود الأصلي بملف ثنائي تماماً مثل برامج الـ C++ أو C# المشفرة.
- يتم حزم النظام مع بيئة تشغيل صامتة، وتوليد ملف تثبيت واحد احترافي: `BayanERP-Setup.exe`.

### خطوات بناء ملف التثبيت:
1. افتح المجلد `desktop\` على جهازك.
2. اضغط مرتين على الملف:
   ```cmd
   build-windows-installer.bat
   ```
   أو افتح موجه الأوامر (CMD) داخل مجلد `desktop` واكتب:
   ```bash
   npm install
   npm run build:exe
   ```
3. ستجد ملف التثبيت الناتج في المجلد:
   ```
   dist-desktop/BayanERP-Setup-1.0.0.exe
   ```
4. يمكنك إرسال هذا الملف مباشرة للعميل؛ بمجرد أن يثبته يظهر له اختصار على سطح المكتب باسم **«بيان ERP»** ويفتح البرنامج كنافذة سطح مكتب مستقلة وسريعة بدون متصفح.

---

## 2. تشغيل النظام على الجوالات (تطبيق هواتف Android و iPhone)

### الطريقة الأولى: التثبيت الفوري كتطبيق PWA (الأسهل والأسرع)
- تم تفعيل معايير **PWA (Progressive Web App)** بالكامل مع ملف `manifest.json` و `service-worker.js`.
- عند فتح رابط النظام من متصفح الجوال (Chrome على أندرويد، أو Safari على آيفون):
  - **على أندرويد:** يظهر زر أزرق في أعلى الشاشة: **«📲 تثبيت التطبيق»**، بمجرد الضغط عليه يُثبت التطبيق فوراً على الهاتف بأيقونته واسمه ويفتح بملء الشاشة كتطبيق مستقل تماماً.
  - **على آيفون:** يضغط العميل على زر المشاركة (Share) في Safari ثم يختار **«إضافة إلى الشاشة الرئيسية (Add to Home Screen)»**.

---

### الطريقة الثانية: بناء ملف APK لأجهزة أندرويد (عبر Capacitor)
تم تجهيز ملف `capacitor.config.json` في المشروع، ويمكنك في أي وقت بناء تطبيق أندرويد أصلي:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap add android
npx cap build
```
سينتج لك مشروع أندرويد استوديو لتوليد ملف `BayanERP.apk`.
